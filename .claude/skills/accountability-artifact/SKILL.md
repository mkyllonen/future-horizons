# Accountability Artifact

Reminders don't work. Calendar blocks don't work. "I'll try" doesn't work. What works is creating a cost that exceeds the pain of doing the thing. This skill generates that cost — as a specific artifact the user can deploy in the next 15 minutes.

## Input

Ask the user for:

1. **The intention.** One sentence. Specific action, specific deadline. "I will [do X] by [date/time]."
2. **Why they haven't done it yet.** One sentence. No excuses allowed — they have to name the real block.
3. **What matters to them socially.** Pick one or more: reputation with peers, spouse/partner, public audience, specific mentor, investor, team, client, former colleagues, rival.

## Pressure test

Before generating the artifact, run these three checks. If any fail, loop back.

- **Is the intention specific and verifiable?** If it's "work on X more" — reject. Ask for a committed output.
- **Is the deadline inside 14 days?** Longer horizons diffuse pressure. Ask them to pick a milestone in the next 14.
- **Have they committed this publicly before and flaked?** If yes, the artifact has to be sharper than last time. Note the pattern in the output.

## Generate one of five artifact types

Pick the type that matches their stakes. Only generate one. Do not give them a menu — pick for them and justify in one line.

### Type 1: Public declaration

A post or message they'll publish the moment they confirm. Format it ready-to-paste.

- Platform: Twitter/X, LinkedIn, Slack group, family text thread, etc.
- Must include: the specific intention, the deadline, and the promise that they'll post the outcome publicly (not just success — outcome, including failure).

### Type 2: Money on the line

A transaction they'll make the moment they confirm. Format with specifics.

- The amount must actually sting — 1-5% of monthly income is typical.
- Destination must be an anti-cause: a charity or person whose work they disagree with.
- Include exact copy-paste instructions for Venmo/Zelle/transfer, plus who to send it to and when.
- If they succeed: money stays where it is. If they fail: the recipient gets it.

### Type 3: Witness accountability

A text they'll send to a specific person the moment they confirm.

- Pick the person based on their social stakes input.
- Text format must state: the intention, the deadline, and a specific check-in question the witness should ask at the deadline.
- Include what the witness should say if the user failed ("What do you want to do about this?" — not "It's OK").

### Type 4: Pre-committed consequence

A self-imposed cost that kicks in if the deadline passes. Generate the concrete setup.

- Examples: delete social media app, cancel a looked-forward-to plan, cold shower streak reset, no coffee for a week.
- The consequence must be automatable or witness-enforced. "I'll just not do X" fails — set up a mechanic.

### Type 5: Burn the boat

A one-way action that makes the intention the only remaining path.

- Examples: buy the plane ticket, announce the service launch publicly, email the client with a delivery date, resign from the thing they've been tolerating.
- Only use this type when the user has been cycling on this for months. It's the sharpest tool.

## Output format

For any chosen artifact type:

**Type chosen:** [1-5]

**Why this one:** [one line]

**The artifact:** [ready-to-deploy content — actual post text, actual transaction instructions, actual message to send]

**Deploy it by:** [time within next 60 minutes]

**Confirm when deployed:** Ask the user to reply with "deployed" once done. If they don't reply within 60 minutes, the skill considers itself failed.

## Never

- Generate vague encouragement.
- Pick Type 1 when stakes are low and it'd just be shouting into a void.
- Pick Type 2 at an amount that doesn't sting.
- Let the user modify the artifact to soften it.
- Offer a fallback. The point is no escape.
